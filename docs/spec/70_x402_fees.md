**Network facts (checked 20 Oct 2026 in Coinbase's x402 docs — re-check before building):** x402 v2 uses packages `@x402/core`, `@x402/evm`, `@x402/fetch` (buyer), `@x402/next` (seller) — the legacy `x402-next`/`x402-fetch` are superseded. Networks use CAIP-2 ids. The CDP facilitator (`https://api.cdp.coinbase.com/platform/v2/x402`, CDP keys) and the x402.org testnet facilitator support **Base Sepolia `eip155:84532`**, **not Ethereum Sepolia**. Base Sepolia USDC: `0x036CbD53842c5426634e7929541eC2318f3dCF7e` (Circle docs). So: **escrow stays on Ethereum Sepolia; x402 fees are paid on Base Sepolia** from a dedicated agent wallet. Say this plainly in docs and in technical details.
